# Контекст для ИИ-помощника

Проект владельца (Telegram @notheine): копировщик сигналов из Telegram-канала в MT5 (FxPro).
Общение с владельцем — по-русски, коротко, без лишних вопросов; он не программист и не хочет
вводить команды сам — по возможности выполняй всё сам.

## Где что

- Код: этот репозиторий. Документация: `docs/` (начни с SETUP.md и ARCHITECTURE.md).
- Сервер: Timeweb Cloud, Амстердам, Ubuntu 26.04, 1 vCPU / 2 ГБ. Код в `/home/fx/copier`, пользователь `fx`,
  службы `fx-xvfb fx-mt5 fx-bridge fx-copier`, управление `fxctl`.
- Секреты только на сервере: `/home/fx/copier/config.yaml`, `session.session` (Telegram-аккаунт копировщика),
  `bot_session.session`, `state.json`, `journal.jsonl`. **Никогда не коммить их и не выводить в чат.**
- Отчёты: бот → группа «FxCopier — сделки» (аккаунт копировщика + @notheine + бот).
- Счёт: FxPro **демо**, тип Hedge, сервер `FxPro-MT5 Demo`. Режим `demo`.

## Доступ к серверу из чата

Облачная среда Claude по SSH на сервер не ходит. Рабочий путь — через связанный Mac владельца
(device_bash): папка `~/FxCopier` подключена, в `~/FxCopier/.ssh/` лежат ключ `fx_key` и скрипт `r`
(`.ssh/r '<команда>'` = ssh root@<сервер> с ключом; IP сервера — внутри скрипта и в панели Timeweb).
Нужна настройка Claude «Allow network egress → All domains». Файлы на Mac пиши через
device_commit_files в **новое имя**, затем `mv` (запись поверх существующего файла может не обновить содержимое) и сверяй md5.

## Правила работы

1. **После каждого изменения кода — коммит и push в `main`** этого репозитория (без напоминаний владельца).
   Описание коммита по-русски, что и зачем. Документацию в `docs/` обновляй в том же коммите.
2. Любое изменение логики → `python tests/test_core.py`; крупное → прогон истории канала
   (выгрузка канала у владельца, в репозиторий не кладётся; стенд — `tests/fake_mt5.py`).
3. Выкатка: см. RUNBOOK.md → «Обновление кода на сервере», затем `systemctl restart fx-copier` и проверка логов.
4. Сделки в `live` (реальные деньги) — только по явной команде владельца.
5. Не трогать позиции, открытые не копировщиком (magic ≠ 770077).
