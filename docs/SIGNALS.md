# Канал и правила разбора

Канал: «Win Win | Торговый клуб» (куратор — Trade INT club). Почти всё — золото (`GOLD` у FxPro).
Проанализирована выгрузка 01.06–01.10.2026: ~250 сигналов, ~1 200 сообщений.

## Форматы сигналов (все поддерживаются)

```
GOLD BUY                 BUY XAUUSD           Покупка XAUUSD        RISKY GOLD LIMIT BUY
BUY @ 4506-4498          📍4162-4158          📍4345-4351           limit buy 4333
TF: 1M                   ✅TP1: 4167          ✅TP1: 4356           ✅TP1: 4355 ...
✅TP1: 4510 … ✅TP4      ✅TP2 … ✅TP3        …                     🔴SL: 4309
❌SL: 4483               🔴SL: 4144
```
Варианты: `TRADE GOLD`, `RISKY`, `LIMIT`, кириллическая «Р» в `TР1`, два тейка в одной строке,
пометки «Стоп длинный занижаем риск» (→ лот ÷2), «пока не вошёл, ждите апдейт» (→ не входим).

## Ошибки в сигналах (≈2%) — не исполняются, уведомление в группу

- SELL с тейками выше входа / BUY с тейками ниже (20.08, 08.09)
- TP3 = `46112` вместо 4611 (27.08), TP1 = `4004` вместо 4404 (12.08)
- зона `4385-4474` (01.09)

Проверки: направление ↔ тейки ↔ стоп, порядок тейков, ширина зоны ≤0.75% цены, TP ≤3%, SL ≤2% от входа.
Если канал **исправит** сообщение — правка обрабатывается (MessageEdited).

## Команды канала → действия

| Текст в канале | Действие |
|---|---|
| «Фиксирую 1/3 TP, стоп переношу в БУ», «ставим стоп-лос на точку входа» | стоп в безубыток (обычно уже сделано автоматически при касании TP1) |
| «Стоп в БУ пока не переставляю» | ничего (отрицание распознаётся) |
| «Закрываем по рынку», «закрываю в безубыток», «закрыть позицию до NFP» | закрыть все позиции сигнала |
| «Сделка закрылась в БУ / по стопу / после 2/3 TP», «Все цели достигнуты» | закрыть остаток, если у нас что-то ещё открыто |
| «Корректировка стоп лоса: на отметку 4333», «кто заходил, стоп переставляем на 4358» | SL → уровень |
| «Переставляем безубыток на первый тейк 4288» | SL → 4288 |
| «Третий тейк на 3997 (опечатка)», «Корректировка 1/3 TP: на 4377», «TP3 значения 4612» | TP соответствующей позиции |
| «Отменяем лимитку» | снять лимитные ордера |
| непонятное с признаками действия («будем закрывать на точке входа», «перезаходим» без уровней) | ничего, в группу «❓ не понял» |
| аналитика, итоги дня, эфиры, длинные посты (>350 символов) | игнорируются |

Цель команды: reply на сигнал → этот сигнал; reply на сообщение из ветки → тот же сигнал;
без reply → последний активный сигнал (в отчёте помечается, если активных было 2).
